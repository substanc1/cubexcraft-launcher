# Безопасность / Security

Нашли уязвимость в лаунчере? Не публикуйте её в issues и обсуждениях. Сообщите приватно:

- GitHub → вкладка **Security** → **Report a vulnerability**;
- или письмом на admin@cubexcraft.site.

Опишите, что и как воспроизвести, на какой версии лаунчера и системе. Исправление придёт всем игрокам через
встроенное автообновление.

Found a vulnerability in the launcher? Please do not post it in issues or discussions. Report it privately
via GitHub → **Security** → **Report a vulnerability**, or email admin@cubexcraft.site with the steps to
reproduce, the launcher version and your OS. Fixes reach every player through the built-in self-update.

Поддерживается только последняя версия лаунчера. Only the latest launcher version is supported.
